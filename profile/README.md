## FinFly

|  |  |
| :--- | :--- |
| **Название команды** | Мухи Дрозофилы |
| **Название проекта** | Персональный финансовый ассистент |
| **Направление проекта** | Долговременная память и lifelong learning агентов |

---

**Короткое описание:**
> Предлагается создать Telegram-бота со встроенной мульти-агентной системой, который по
отправленным чекам будет вести единый учет расходов со всех счетов пользователя и 
предлагать оптимизацию расходов на основе современных инструментов.


**Мотивация:**
> Сегодня практически каждый человек имеет несколько счетов в различных банках, 
следить за расходами (и пытаться их оптимизировать) становится труднее. Наше приложение
позволяет быстро вести учет трат, а также оптимизировать их через персональные рекомендации
(лучший выбор категорий кэшбэка, бонусных карт)


**Целевая аудитория:**

  - **Физические лица в возрасте 18-35 лет**, не имеющие достаточного времени на анализ расходов
  - **ИП и малый бизнес**, взаимодействующие с разными банками

---

**Мультиагентная система будет содержать:**

 - **OCR-агента** (первичная обработка полученного чека)
 - **Parser-агента** (извлечение всех необходимых полей из обработанного чека и определяет ненужные для учета операции)
 - **Categorize-агент** (определяет категории расходов)
 - **Describer-агент** (пишет понятное описание для операций)
 - **Recommendations-агент** (составляет персональные рекомендации по тратам)

**Метрики оценки качества проекта:**
  - % корректно распознанных символов/полей OCR-агентом
  - % правильно извлеченных полей Parser-агентом
  - % верно определленных мусорных переводов (переводов между собственными счетами)
  - время обработки одного чека
